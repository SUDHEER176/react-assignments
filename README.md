# React assignments

Two small React apps, each in its own folder with its own `package.json`.

| Folder | What it is |
| --- | --- |
| [`chat-app`](chat-app) | Team chat: random users per message, likes, emoji picker, @mentions, dark mode and an Express + socket.io server. |
| [`photo-gallery`](photo-gallery) | Infinite-scroll photo list from the Picsum feed, with a like counter on every photo. |

Both use Vite. To run one:

```bash
cd chat-app        # or photo-gallery
npm install
npm run dev
```

Each folder's README has the details, and the original assignment briefs sit next to the code.
